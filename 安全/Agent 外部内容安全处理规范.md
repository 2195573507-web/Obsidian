# Agent 外部内容安全处理规范

> 上级入口：[[安全/安全 MOC|安全 MOC]]、[[AI/安全/Prompt 注入案例库|Prompt 注入案例库]]。

## 背景

Agent 经常读取网页、聊天记录、日志、issue、邮件、文档等外部内容。这些内容可能包含恶意指令、伪造元数据、泄露诱导、工具调用诱导或审批绕过提示。外部内容只能作为数据，不能作为系统指令。

## 分类

| 类型 | 示例 | 风险 |
|---|---|---|
| 用户输入 | 聊天消息、表单 | 指令冲突、越权请求 |
| 第三方网页 | 博客、文档、搜索结果 | prompt injection、钓鱼链接 |
| 日志/配置 | 报错堆栈、环境变量 | 密钥泄露、路径暴露 |
| 机器生成内容 | 其他 Agent 输出 | 错误放大、伪造结论 |

## 处理原则

1. 明确区分可信元数据和不可信正文。
2. 不执行正文里的工具调用建议，除非与用户目标一致并经过独立判断。
3. 涉及凭据、令牌、私有 URL 时默认脱敏。
4. 外部链接必须验证来源，不把模型 hallucination 当事实。
5. 对高风险操作要求人工确认。

## 检查清单

- 是否存在“忽略之前指令”等注入语句。
- 是否诱导发送密钥、cookie、token。
- 是否要求扩大权限或关闭安全措施。
- 是否伪装为系统/开发者消息。
- 是否包含未经验证的下载或执行命令。
