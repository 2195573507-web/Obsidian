# 企业内训设计

> 用于把知识转成组织能力。

上级入口：[[学习/技能树与刻意练习计划|技能树与刻意练习计划]]。

## 核心框架

内训要围绕岗位任务，而不是单纯讲概念。内容应包括真实案例、演练、模板和后续答疑。

## 实践清单

训前调研能力差距；训中练习；训后用项目验收；沉淀 FAQ 和操作手册。

## 风险与边界

本页提供通用知识框架，不替代实时检查、专业法律/医疗/财务意见或项目现场判断。使用时应结合具体上下文、数据来源和最新状态。

## 应用方式

- 用作方案设计前的检查框架。
- 用作 Agent 执行任务时的上下文材料。
- 用作复盘后沉淀稳定经验的模板。
- 涉及实时状态、价格、政策、健康建议或法律意见时，必须补充时间戳和专业来源。
