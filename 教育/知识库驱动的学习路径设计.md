# 知识库驱动的学习路径设计

> 上级入口：[[教育/教育 MOC|教育 MOC]]、[[学习/技能树与刻意练习计划|技能树与刻意练习计划]]。

## 目标

把零散笔记组织成可学习、可复习、可实践的路径。学习路径不是简单目录，而是从概念、案例、练习、项目到复盘的递进结构。

## 结构

1. 入门概念：术语、背景、边界。
2. 核心模型：关键原理、常见误区。
3. 操作手册：步骤、命令、模板。
4. 案例库：成功案例、失败案例、复盘。
5. 练习任务：小实验、验收标准。
6. 输出项目：报告、工具、自动化流程。

## 设计原则

- 每个阶段只解决一个认知负荷。
- 学习页链接到实践页。
- 实践页链接到复盘模板。
- 对过期内容设置复查周期。
- 用 MOC 承担导航，用专题页承担理解。
