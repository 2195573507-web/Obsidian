# API 文档质量清单

> 用于检查接口文档是否能被开发者直接使用。

上级入口：[[软件工程/API 错误模型与响应规范|API 错误模型与响应规范]]。

## 核心框架

API 文档需要路径、方法、认证、参数、请求示例、响应示例、错误码、分页、限流和版本说明。

## 实践清单

示例必须可运行；错误码必须说明原因和处理；变更必须有迁移说明。

## 风险与边界

本页提供通用知识框架，不替代实时检查、专业法律/医疗/财务意见或项目现场判断。使用时应结合具体上下文、数据来源和最新状态。

## 应用方式

- 用作方案设计前的检查框架。
- 用作 Agent 执行任务时的上下文材料。
- 用作复盘后沉淀稳定经验的模板。
- 涉及实时状态、价格、政策、健康建议或法律意见时，必须补充时间戳和专业来源。
