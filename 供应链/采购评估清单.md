# 采购评估清单

> 用于选择软件、硬件、云服务和外包供应商。

上级入口：[[法律合规/隐私政策与数据边界清单|隐私政策与数据边界清单]]。

## 核心框架

采购评估不仅看价格，还要看能力、交付、支持、合规、锁定风险、退出成本和历史口碑。

## 实践清单

列 must-have 和 nice-to-have；做 PoC；检查合同中的 SLA、数据归属、续费、违约和退出条款。

## 风险与边界

本页提供通用知识框架，不替代实时检查、专业法律/医疗/财务意见或项目现场判断。使用时应结合具体上下文、数据来源和最新状态。

## 应用方式

- 用作方案设计前的检查框架。
- 用作 Agent 执行任务时的上下文材料。
- 用作复盘后沉淀稳定经验的模板。
- 涉及实时状态、价格、政策、健康建议或法律意见时，必须补充时间戳和专业来源。
