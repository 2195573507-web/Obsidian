# Agent 运维值班职责分工

> 上级入口：[[人力/人力 MOC|人力 MOC]]、[[管理/自动化任务复盘模板|自动化任务复盘模板]]。

## 背景

当 Agent 系统承担日报、巡检、投递、补跑和知识库维护时，需要明确谁看告警、谁审批变更、谁复盘失败。即使是个人系统，也可以用角色分工来降低混乱。

## 角色

- 观察者：查看监控和任务状态。
- 处置者：执行补跑、降级、暂停任务。
- 审批者：确认生产变更和敏感动作。
- 复盘者：整理事件、更新 runbook。

## 值班清单

- 每日查看 P0/P1 自动化失败。
- 每周检查重复失败任务。
- 每月复查任务价值和成本。
- 重大故障后更新知识库和模板。
