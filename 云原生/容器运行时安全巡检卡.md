# 容器运行时安全巡检卡

> 上级入口：[[云原生/云原生 MOC|云原生 MOC]]、[[安全/生产变更授权队列规范|生产变更授权队列规范]]。

## 目标

把容器安全资讯转换成只读巡检卡，先确认资产和影响，再进入授权变更，而不是直接升级生产组件。

## 巡检项

- runc/containerd/Docker 版本。
- 是否暴露 Docker socket。
- 容器是否 privileged。
- 是否挂载宿主敏感目录。
- 镜像来源和签名策略。
- 运行时 seccomp/apparmor 配置。
- Kubernetes 节点运行时版本。

## 输出格式

- 资产范围。
- 当前版本。
- 是否命中公告影响范围。
- 建议动作：无需处理 / 观察 / 计划升级 / 紧急修复。
- 回滚与验证方式。
