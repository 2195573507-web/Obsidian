# 自动化任务分级

> 用于判断哪些任务适合自动化。

上级入口：[[AI/Agent/Cron Agent 任务设计规范|Cron Agent 任务设计规范]]。

## 核心框架

自动化可分为提醒、采集、整理、执行、决策建议和自动决策。越接近自动决策，风险越高，越需要审批和回滚。

## 实践清单

优先自动化高频、低风险、规则明确、可验证的任务。低频高风险任务只自动生成候选方案。

## 风险与边界

本页提供通用知识框架，不替代实时检查、专业法律/医疗/财务意见或项目现场判断。使用时应结合具体上下文、数据来源和最新状态。

## 应用方式

- 用作方案设计前的检查框架。
- 用作 Agent 执行任务时的上下文材料。
- 用作复盘后沉淀稳定经验的模板。
- 涉及实时状态、价格、政策、健康建议或法律意见时，必须补充时间戳和专业来源。
