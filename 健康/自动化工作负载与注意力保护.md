# 自动化工作负载与注意力保护

> 上级入口：[[健康/健康 MOC|健康 MOC]]、[[效率/深度工作与注意力管理|深度工作与注意力管理]]。

## 背景

自动化任务越多，通知、失败、补跑和巡检就越容易占用注意力。知识库和 Agent 系统需要服务人的节奏，而不是制造持续打断。

## 风险信号

- 高频任务反复失败并持续通知。
- 每个日报都要求即时阅读。
- 任务结果没有优先级。
- 失败信息只有技术细节，没有行动建议。
- 人需要不断追问“现在怎么样了”。

## 设计原则

1. 高频状态合并为摘要。
2. 非紧急失败延迟汇报或归档。
3. 只把需要决策的事项推给人。
4. 把“已处理”和“待处理”分开。
5. 夜间或专注时段减少低价值通知。

## 实践清单

- 为每类自动化任务定义通知等级。
- 对连续失败设置静默阈值。
- 每日只汇总一次低优先级状态。
- 对补跑任务使用结论先行报告。
- 把长期知识沉淀到知识库，减少重复解释。
