# Agent 浏览器生态观察框架

> 上级入口：[[行业研究/行业研究 MOC|行业研究 MOC]]、[[AI/Agent/浏览器 Agent 安全默认模型|浏览器 Agent 安全默认模型]]。

## 观察维度

Agent 浏览器生态需要同时看能力、隔离、安全、可观测性和产品体验，而不是只看“能不能自动点网页”。

## 维度清单

- 浏览器隔离：profile、cookie、下载目录、权限。
- 操作能力：点击、填写、上传、下载、截图、DOM 读取。
- 安全边界：外部内容注入、登录态、敏感动作确认。
- 可观测性：步骤日志、截图、失败恢复。
- 开发者体验：API、测试、CI、headless/headful。
- 产品体验：用户确认、进度反馈、失败兜底。

## 评估问题

1. 是否默认隔离登录态。
2. 是否能限制可访问域名。
3. 是否能记录可复核证据。
4. 是否支持人工接管。
5. 是否有敏感动作确认机制。
