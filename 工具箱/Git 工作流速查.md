# Git 工作流速查

> 用于规范分支、提交、回滚和协作。

上级入口：[[软件工程/CI CD 发布流水线|CI CD 发布流水线]]。

## 核心模型

Git 工作流包括分支命名、commit 粒度、PR 审查、冲突解决、tag 和回滚。

## 执行步骤

提交前看 diff；提交信息写为什么；危险 reset/rebase 前备份；发布用 tag。

## 边界与风险

使用时注意区分通用知识与当前事实；涉及法规、健康、财务、安全状态时必须补充最新来源和时间戳。

## 可复用输出

- 一页式摘要：背景、目标、约束、方案、风险、下一步。
- 执行清单：输入、步骤、验收、回滚、负责人。
- 复盘记录：事实、根因、改进、沉淀链接。
