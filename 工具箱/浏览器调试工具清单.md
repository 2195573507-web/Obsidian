# 浏览器调试工具清单

> 用于前端、网络和性能调试。

上级入口：[[前端/表格与列表体验设计|表格与列表体验设计]]。

## 核心模型

浏览器 DevTools 包含 Elements、Console、Network、Performance、Application、Security。

## 执行步骤

排查页面问题先看 console 错误，再看 network 状态码和 payload，再看 DOM/CSS。

## 边界与风险

使用时注意区分通用知识与当前事实；涉及法规、健康、财务、安全状态时必须补充最新来源和时间戳。

## 可复用输出

- 一页式摘要：背景、目标、约束、方案、风险、下一步。
- 执行清单：输入、步骤、验收、回滚、负责人。
- 复盘记录：事实、根因、改进、沉淀链接。
