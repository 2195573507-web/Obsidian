# AI 自动化任务成本估算

> 上级入口：[[财务/财务 MOC|财务 MOC]]、[[AI/模型路由、成本控制与降级|模型路由、成本控制与降级]]。

## 背景

日报、巡检、调研、复盘等自动化任务如果没有成本意识，容易在上游故障、频繁补跑或上下文过大时放大开销。成本估算用于决定哪些任务值得实时跑，哪些可以延后或降级。

## 成本构成

- 模型输入 token。
- 模型输出 token。
- 搜索/API 调用次数。
- 工具运行时间。
- 存储与索引成本。
- 人工复核时间。

## 估算公式

单次任务成本 = 输入 token 成本 + 输出 token 成本 + 外部 API 成本 + 失败重试成本。

月成本 = 单次成本 × 每日次数 × 30 × 成功/重试放大系数。

## 控制策略

1. 高频任务使用短上下文和低成本模型。
2. 长报告任务设置每日上限。
3. 上游失败时不要立即大规模补跑。
4. 对低价值通知类任务合并发送。
5. 把可复用资料缓存到知识库，减少重复检索。

## 复盘指标

- 每类任务平均 token。
- 失败重试放大系数。
- 成功产物数量。
- 用户实际阅读或使用次数。
- 单份有效报告成本。
