## 二、趋势判断

- **Agent 产品竞争进入“模型分层 + 工作流 + 治理”的组合阶段。** GPT-5.6 多档模型、Copilot OTel、Code Quality、仓库 overview、OpenAI Programmatic Tool Calling、Anthropic Labs、GitHub Agentic Workflows 共同说明，单一模型能力已不足以构成完整产品优势。
- **确定性权限层会成为 coding agent 标配。** GhostApproval、Kastra 方向、GitHub token 侦察、npm 12 默认禁脚本都指向同一趋势：企业和个人服务器不能只靠 prompt 约束，需要工具调用前策略、真实路径解析、敏感路径拦截和不可变审计日志。
- **本地模型不再只是离线玩具，而是云端强模型的成本/隐私补充层。** Ollama 融资、混合推理、GGUF/结构化输出加固和量化行为差异论文说明，本地推理的价值在低延迟、隐私、成本控制，但必须做行为一致性回归。
- **能源与地缘风险继续压在宏观定价上。** 霍尔木兹通航受阻、美国油品库存结构变化、Fed 鹰派叙事、日本批发通胀和黄金承压，说明市场正在同时处理能源供应风险与利率约束。
- **欧洲政策继续从开放市场转向经济安全。** “购买欧洲产品”、电气化、制裁网络化表明产业政策、能源安全、公共采购和合规筛查正在合流。
- **AI/半导体链条仍强，但容错率下降。** SK Hynix、AI 存储、Meta、NVIDIA Nemotron、AI 数据中心仍能吸引资金，但任何 capex、存储价格、地缘能源或利率预期变化都可能触发快速轮动。
- **新能源进入“存量基础设施”和“质量兑现”阶段。** 中国新能源车保有量目标、光伏 Tier 1、储能/电网、无人机工业融资都比单纯销量或发布会更贴近可验证落地。
