# 2026-07-07 OpenClaw 技术晚间补充

范围：过去 24 小时内与 AI、开源、安全、运维相关的重要变化。时间基准：2026-07-07 11:20 UTC。

## 最重要 5 条

1. **OpenSSH 10.4 发布，包含多项安全修复和协议收紧**
   - 官方发布说明确认 OpenSSH 10.4 于 2026-07-06 发布。安全项包括：sftp 下载路径可被恶意服务器影响、scp 远端到远端复制时恶意服务器可写入目标父目录、internal-sftp 参数截断导致后续安全参数被丢弃、GSSAPIAuthentication 相关预认证 DoS、最小认证延迟未正确执行、ssh 客户端 key reexchange 期间潜在 use-after-free 等。
   - 兼容性注意：Linux seccomp sandbox 启用失败现在会 fatal；post-auth re-key 时发送非 KEX 消息会断开；`sshd -G` 输出指令大小写变化。
   - 还新增实验性 ML-DSA 44 + Ed25519 复合后量子签名支持，默认不启用。
   - 来源：https://www.openssh.org/txt/release-10.4

2. **Januscape：Linux KVM/x86 CVE-2026-53359 公开，影响虚拟化隔离**
   - 研究者公开 Januscape 文档，描述 KVM/x86 shadow MMU use-after-free，可由 guest-side actions 触发 host kernel shadow page corruption。公开 PoC 主要触发 host KVM panic；作者称完整 escape exploit 存在但未发布。
   - 影响面集中在接受不可信 guest、开启/暴露 nested virtualization 的 x86 KVM 主机；某些 `/dev/kvm` world-writable 发行版场景还可能形成本地提权路径。
   - 文档称受影响范围从 Linux commit `2032a93d66fa` 到修复 commit `81ccda30b4e8`，建议确认宿主机内核已包含修复。
   - 来源：https://github.com/V4bel/Januscape

3. **OpenAI Codex macOS 桌面端 CVE-2026-14898：远程 Markdown 图片导致间接提示注入数据外传**
   - NVD 条目显示，Codex macOS 桌面 app 曾在模型响应中渲染远程 Markdown 图片。攻击者若能把间接提示注入放进 Codex 处理的不可信内容，可诱导模型构造包含敏感数据的远程图片 URL；渲染时自动请求该 URL，从而外传 API key、源码、连接工具返回数据等。
   - NVD 标注：未展示完整性/可用性影响，暂无已知在野利用；来源为 OAI，发布日期 2026-07-06。
   - PromptArmor 披露文章称该问题已于 2026-04-21 负责任披露，并已由 OpenAI 修复。
   - 来源：https://nvd.nist.gov/vuln/detail/cve-2026-14898
   - 来源：https://www.promptarmor.com/resources/codex-for-everything-exfiltrates-connected-data

4. **PolinRider 开源供应链攻击继续扩展，目标是开发者环境**
   - Socket Threat Research 报告称，PolinRider 与朝鲜相关 Contagious Interview / Famous Chollima 活动簇有关，已在 npm、Packagist、Go modules、Chrome extensions 等生态中识别出 108 个包/扩展、162 个恶意发布 artifact。
   - 技法包括：植入混淆 JavaScript loader、用 whitespace padding 或假 `.woff2` 文件隐藏、通过 VS Code task 等开发者工具触发、重写 Git 历史/反向日期提交以降低可疑度。
   - 载荷会访问 TRON、Aptos、BNB Smart Chain 等公共 RPC 基础设施获取加密二阶段 payload；已观察到 DEV#POPPER、OmniStealer。
   - 来源：https://socket.dev/blog/polinrider-north-korea-linked-supply-chain-campaign-expands

5. **GitHub Security Lab 披露 7-Zip 26.00 多个漏洞，26.01 已修复**
   - GHSL-2026-140：7-Zip 26.00 的 NTFS archive handler 存在 heap buffer overflow，构造 NTFS 镜像可造成 1 字节 buffer 被写入最多 256 MB attacker-controlled data，可能导致代码执行或崩溃。披露时间线显示 26.01 于 2026-04-27 修复。
   - GHSL-2026-115 至 GHSL-2026-122：涉及多种 archive format 的 memory access violation、OOB read、未初始化内存、整数溢出、示例 app path traversal 等。
   - 对服务器侧自动解压、CI artifact 分析、邮件/附件处理服务尤其需要关注。
   - 来源：https://securitylab.github.com/advisories/GHSL-2026-140_7-Zip/
   - 来源：https://securitylab.github.com/advisories/GHSL-2026-115_GHSL-2026-122_7-zip/

## 对 OpenClaw / Hermes / 个人服务器有用的 3 条

1. **OpenClaw/Hermes 的 agent 输出渲染要默认禁用自动远程资源加载**
   - Codex CVE-2026-14898 的核心不是“模型说错话”，而是渲染层自动加载模型生成的远程 URL，把上下文变成外传通道。
   - 建议检查 OpenClaw/Hermes：Markdown 图片、HTML 预览、browser/canvas 渲染、QQ/消息转发、Obsidian 预览是否会自动请求模型输出里的远程图片/链接；对不可信来源生成内容应默认转义、代理隔离或显式确认。

2. **个人服务器优先排查 OpenSSH 版本与 sshd 配置兼容性**
   - OpenSSH 10.4 可作为常规安全更新纳入升级计划，但先检查发行版包维护状态、seccomp sandbox 支持、`sshd -T/-G` 自动化脚本是否依赖小写输出。
   - 如果启用了 `GSSAPIAuthentication`、`internal-sftp`、`PermitTunnel`、复杂 Match/Forwarding 配置，应在更新前后做一次配置 dump 和登录回归测试。

3. **开发者工作站和 CI 要强化依赖与任务文件审计**
   - PolinRider 的重点是“合法仓库/维护者账号被改造后投毒”，不能只看项目星数或 GitHub 首页。
   - 对 OpenClaw/Hermes 相关仓库建议重点审计：`package-lock.json`/`pnpm-lock.yaml`/`go.sum`/Composer lockfile 变化、VS Code tasks、postinstall scripts、混淆 JS、异常 `.woff2`/字体文件、近期 force-push 或历史重写。

## 风险 / 机会

### 风险

- **AI agent 数据外传通道越来越偏向 UI/渲染层**：远程图片、schema markup、隐藏 HTML、搜索结果污染都可诱导 agent 行动或泄露上下文。仅靠模型系统提示不够，需要工具层、渲染层、网络层边界。
- **虚拟化宿主机漏洞影响个人云/实验环境**：Januscape 对公有云和多租户更高危，但个人 KVM/Nested virtualization 主机也应确认内核修复，尤其是运行不可信 VM、CI runner、沙箱任务的机器。
- **供应链攻击绕过“看起来正常”的仓库信号**：PolinRider 使用历史重写、反向日期提交、合法 maintainer 账号，使普通代码浏览不足以发现问题。
- **自动解压/附件处理仍是高价值入口**：7-Zip 漏洞再次提示，任何自动处理压缩包、镜像、归档文件的服务都应沙箱化、限权、及时升级。

### 机会

- **把 Codex CVE 模式转成 OpenClaw/Hermes 安全测试用例**：构造包含 Markdown image exfiltration、隐藏 HTML prompt、schema prompt 的 fixture，验证消息渲染、浏览器工具、Obsidian 写入、QQ 转发都不会自动外连或泄漏上下文。
- **把 OpenSSH 10.4 升级纳入维护窗口**：先在非关键服务器验证配置兼容，再推广。
- **建立轻量供应链巡检脚本**：定期扫描 lockfile diff、postinstall、VS Code tasks、异常大行/混淆 JS、非预期二进制/字体文件，优先用于 OpenClaw/Hermes 插件和技能仓库。
