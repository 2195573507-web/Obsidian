## 最重要 5 条

### 1. Linux 内核 “Bad Epoll” 本地提权漏洞披露（CVE-2026-46242）
- 摘要：The Hacker News 报道，新披露的 Linux 内核 epoll use-after-free 漏洞可使普通本地用户提权到 root；影响 Linux 桌面、服务器和 Android。报道称 6.4 及之后内核受影响，修复提交为 `a6dc643c6931`，暂无公开证据显示已被真实攻击利用，也未见其进入 CISA KEV（按报道时点）。
- 影响：对个人服务器、容器宿主机、CI/构建机尤其重要；一旦攻击者获得普通账号、Web shell 或容器内可利用路径，可能进一步扩大权限。
- 建议：关注发行版内核安全更新；如运行 6.4+ 内核，优先确认补丁/回补状态；避免给不可信用户 shell；加强容器/服务账号最小权限。
- 状态：媒体报道 + 公开 PoC/技术写作；是否存在野外利用未确认。
- 来源：https://thehackernews.com/2026/07/new-bad-epoll-linux-kernel-flaw-lets.html

### 2. JadePuffer 勒索攻击被称使用 AI Agent 自动执行全链路攻击
- 摘要：BleepingComputer 基于 Sysdig 报告称，JadePuffer 勒索/数据库勒索行动使用 LLM agent 自动完成侦察、凭据窃取、横向移动、持久化、提权和数据加密。初始入口为已知 Langflow RCE（CVE-2025-3248），随后枚举 PostgreSQL/MinIO/Nacos，并在服务器上设置 30 分钟回连 cron。
- 影响：暴露的 AI 应用框架、低加固 Langflow、Nacos、MinIO、数据库凭据泄露会成为高风险组合。
- 建议：检查是否部署 Langflow/Nacos；确认 CVE-2025-3248 已修复；清理环境变量中的长期凭据；审计异常 cron、MinIO/API 访问、数据库大批量读写与配置表异常。
- 状态：“首个全 AI agent 勒索案例”的说法来自研究方，独立确认不足，标注未确认；攻击链细节有公开报告支撑。
- 来源：https://www.bleepingcomputer.com/news/security/jadepuffer-ransomware-used-ai-agent-to-automate-entire-attack/

### 3. 朝鲜相关 PolinRider 供应链活动扩展：108 个恶意包/扩展
- 摘要：The Hacker News 报道，Contagious Interview 相关朝鲜威胁活动 PolinRider 发布/污染 108 个包和浏览器扩展，涉及 npm、Composer/Packagist、Go modules、Chrome 扩展等，Socket 称该活动仍活跃，并可能继续通过维护者账号和合法仓库发布感染版本。
- 影响：开发者工作站、CI、自动化部署链路、依赖更新机器人存在风险；对 OpenClaw/Hermes 这类依赖 Node/Go/Python 生态与自动化工具的环境尤其需要防范供应链投毒。
- 建议：锁定依赖版本与校验哈希；CI 中限制安装脚本权限；避免在高权限环境直接运行未知仓库；启用 Dependabot/OSV/Socket/Trivy 等扫描但不要盲目信任单一工具。
- 状态：来自媒体与 Socket 研究；具体包清单需结合官方/研究方列表二次核验。
- 来源：https://thehackernews.com/2026/07/north-korean-hackers-publish-108.html

### 4. Debian 发布 php8.4 安全更新（DSA-6377-1）
- 摘要：Debian 安全页显示 2026-07-04 发布 DSA-6377-1，修复 php8.4；安全追踪器显示 trixie 原版本 `8.4.16-1~deb13u1` vulnerable，安全版本 `8.4.23-1~deb13u1` fixed。
- 影响：运行 Debian trixie 且部署 PHP 8.4 Web 服务的服务器需要尽快更新；面向公网的 PHP 应用风险更高。
- 建议：执行常规安全更新；检查 `php8.4` 包版本；更新后按需重启 php-fpm / Web 服务；确认自动安全更新覆盖 Debian security 源。
- 状态：官方 Debian 安全追踪器确认。
- 来源：https://www.debian.org/security/ ，https://security-tracker.debian.org/tracker/DSA-6377-1

### 5. CISA KEV 近期新增 SharePoint / SimpleHelp 等已知被利用漏洞，窗口内未见更新但仍需复查暴露面
- 摘要：CISA KEV 当前目录版本为 2026-07-01，最近条目包括 Microsoft SharePoint Server CVE-2026-45659（远程代码执行，due 2026-07-04）与 SimpleHelp CVE-2026-48558（OIDC 签名验证缺陷导致认证绕过，due 2026-07-02）。Help Net Security 周回顾也提到 SimpleHelp 漏洞被利用。
- 影响：虽然不是过去 24 小时新增，但在本次 24h 资讯窗口内仍处于应急修复/复核期；如果个人服务器或客户环境使用远程支持、SharePoint、OIDC 集成，风险较高。
- 建议：复查公网资产、远程支持软件、OIDC 配置；对管理后台加 IP allowlist / VPN；检查异常登录与新建技术员会话。
- 状态：CISA KEV 官方确认“已知被利用”；具体攻击范围需结合各厂商公告。
- 来源：https://www.cisa.gov/sites/default/files/feeds/known_exploited_vulnerabilities.json ，https://www.helpnetsecurity.com/2026/07/05/week-in-review-simplehelp-vulnerability-exploited-oracle-ebs-payments-flaw-under-attack/

## 对 OpenClaw / Hermes / 个人服务器有用的 3 条

1. **优先做内核与宿主机补丁盘点**  
   Bad Epoll 是本地提权类漏洞；即使服务没有直接 root 运行，只要 Web 服务、Agent、CI、容器逃逸链拿到普通权限，就可能升级。建议把 `uname -a`、发行版内核包安全更新、重启需求纳入每日健康检查。

2. **把 AI/自动化服务当成高价值入口防护**  
   JadePuffer 案例再次说明：Langflow、Nacos、MinIO、数据库、环境变量密钥一旦组合暴露，攻击会快速自动化。OpenClaw/Hermes 所在服务器应避免把实验性 AI Web 服务直接暴露公网；密钥放到最小权限账户；定期扫异常 cron、systemd timer、反连进程。

3. **加强依赖供应链闸门**  
   PolinRider 覆盖 npm、Go、Composer、Chrome 扩展等生态。建议对 OpenClaw/Hermes 的插件、脚本和依赖更新采用：锁文件 + 审核安装脚本 + 最小权限 CI + 扫描报告留痕；不要在宿主机 root 环境直接运行陌生仓库的安装命令。

## 风险 / 机会

### 风险
- Linux 6.4+ 内核本地提权若被武器化，可能成为“拿到低权限后快速 root”的通用后渗透链条。
- AI agent 让低成本攻击自动适配失败、重试、横向移动；传统只看固定 IOC 的检测会更吃力。
- 开源供应链攻击仍在跨生态扩散，开发者工具、CI 凭据、浏览器扩展是重点入口。
- 远程支持/OIDC/管理后台类漏洞一旦进入 KEV，通常代表已存在真实利用，需要按暴露面优先级处理。

### 机会
- 将每日资讯转化为自动化检查项：内核版本、待重启、异常 cron、暴露端口、依赖扫描、备份恢复演练状态。
- 对 AI/Agent 服务建立“默认内网 + 反代鉴权 + 短期凭据 + 审计日志”的基线。
- 在 OpenClaw/Hermes 监控中增加“安全运维卡片”：内核补丁状态、Docker/K8s 组件版本、最近失败登录、备份最近成功时间、关键目录变更。
