## 最重要 5 条

1. **ACSC 警告全球 CMS/插件大规模利用活动，重点是 WebShell 投放。**
   - 澳大利亚网络安全中心（ACSC）称攻击者正在全球扫描 WordPress、Craft CMS、MaxSite CMS、MetInfo CMS、Joomla JCE 等 CMS/插件漏洞，利用类型包括未认证文件上传、RCE、SSRF、反序列化等，目标是部署 WebShell。
   - 影响：个人服务器上只要有 WordPress/Joomla/Craft 或历史插件，就需要立即检查插件版本、Web 目录异常文件、Web 访问日志、异常子进程。
   - 来源：https://www.cyber.gov.au/about-us/view-all-content/alerts-and-advisories/large-scale-exploitation-campaign-targeting-website-content-management-systems-cms
   - 补充报道：https://www.bleepingcomputer.com/news/security/australia-warns-of-global-campaign-targeting-vulnerable-cms-platforms/

2. **`jscrambler@8.14.0` npm 包被投毒，安装时执行跨平台原生窃密程序。**
   - Socket 与多家安全团队确认，2026-07-11 发布的 `jscrambler@8.14.0` 添加了未记录的 `preinstall` hook 和隐藏原生二进制，Linux/macOS/Windows 安装时均可能执行。目标包括云凭据、CI/构建环境密钥、浏览器/通讯工具会话、AI 编码工具配置等。
   - 对运维的意义：CI runner、构建机和开发机应检查 lockfile、npm 缓存、安装日志；若安装过该版本，应按密钥泄露处理并轮换凭据。
   - 来源：https://socket.dev/blog/jscrambler-supply-chain-attack
   - 补充报道：https://thehackernews.com/2026/07/compromised-jscrambler-8140-npm-release.html

3. **“Ghostcommit”展示图片内提示注入可诱导 AI 编码代理泄露 `.env`。**
   - 研究者构造 PR，把恶意指令藏在 PNG 图片中；部分 AI 代码审查器不会检查图片，后续编码代理读取项目约定/图片后可能读取 `.env` 并把密钥编码写入源码。
   - 对 OpenClaw/Hermes 特别相关：AGENTS.md、文档图片、PR 附件、截图等都应视为不可信输入；Agent 不应在普通代码任务中读取 `.env`、凭据文件或把秘密以“编码常量”等形式写入代码。
   - 来源：https://www.bleepingcomputer.com/news/security/ghostcommit-hides-prompt-injection-in-images-to-fool-ai-agents-steal-secrets/
   - 研究 PoC/披露：https://github.com/asset-group/ghostcommit

4. **Zimbra 发布 10.1.19，修复 Classic Web Client 高危邮件触发漏洞。**
   - Zimbra 官方称 Classic Web Client 存在安全问题，特制邮件打开后可运行恶意代码，可能访问邮箱信息、会话数据或账号设置；官方建议使用 Classic Web Client 的客户尽快升级到 ZCS 10.1.19。
   - 状态：官方公告称严重性 High；The Hacker News 报道称尚未分配 CVE，未见官方确认已被在野利用，标注为“未确认在野利用”。
   - 来源：https://blog.zimbra.com/2026/07/patch-release-update-zimbra-10-1-19/
   - 补充报道：https://thehackernews.com/2026/07/critical-zimbra-flaw-could-let-crafted_0483473395.html

5. **多个攻击团伙长期利用执法机构 Web 应用、网络设备与邮件网关。**
   - SentinelOne 披露，巴基斯坦多家执法机构遭疑似中国、印度相关威胁团伙长期间谍活动，涉及 Web 应用服务器、网络设备、Fortinet FortiMail，使用 PlugX、ShadowPad、Cobalt Strike、Remcos RAT 等。
   - 对个人/小型服务器的启发：公网 Web 应用与网络边界设备被攻陷后可成为长期驻留点；仅修应用漏洞不够，还要查反向连接、异常服务、计划任务、Web 根目录植入文件。
   - 来源：https://thehackernews.com/2026/07/hackers-weaponize-balochistan-police.html
   - 原始研究：https://www.sentinelone.com/labs/one-target-china-india-espionage-converge-on-pakistani-law-enforcement/

## 对 OpenClaw / Hermes / 个人服务器有用的 3 条

1. **把 Agent 输入边界写得更硬。**
   - 图片、Markdown、AGENTS.md、外部 issue/PR、网页抓取内容都应作为不可信数据处理。
   - 建议：普通代码任务默认禁止读取 `.env`、SSH key、cloud credential、token 文件；若确需读取，必须有明确用户授权和最小化输出。

2. **给 CI/构建机做一次 npm 供应链检查。**
   - 检查 `package-lock.json` / `pnpm-lock.yaml` / `yarn.lock` 是否出现 `jscrambler@8.14.0`。
   - 若出现：升级到 `8.15.0` 或回退到 `8.13.0`，清理缓存，审计 7 月 11 日以来 CI job 日志、Node 子进程、临时目录执行记录，并轮换可被构建环境读取的密钥。

3. **Web 站点按“已被扫描”假设做轻量巡检。**
   - 对 WordPress/Joomla/Craft 等：更新 CMS 与插件，删除不用插件，尽量让 Web 目录只读，监控新增 PHP/可执行文件，检查 Web 进程异常子进程。
   - 对 OpenClaw/Hermes 暴露面：确认公网入口只暴露必要服务，管理后台/调试端点不直接暴露，日志中出现异常 POST、上传、路径遍历请求时及时告警。

## 风险 / 机会

- **风险：供应链和 Agent 安全正在合流。** npm 包投毒会直接攻击开发机/CI；图片提示注入会绕过文本审查并诱导 Agent 泄密。Hermes/OpenClaw 这类自动化系统需要同时管控依赖安装、外部内容读取、秘密文件访问。
- **风险：公网 CMS 仍是最容易规模化打穿的入口。** 今日 ACSC 提到的插件列表覆盖大量常见 WordPress 生态，攻击者目标不是“打首页”，而是部署 WebShell 后长期驻留、窃取凭据、横向移动。
- **机会：可以把检测点做得很具体。** 监控 Web 目录新增文件、Web 进程子进程、npm install scripts、CI 临时目录执行、Agent 读取秘密文件行为，成本低但收益高。
- **机会：npm 12 默认关闭依赖安装脚本是可用防线。** 可考虑在开发/CI 环境逐步启用更严格的安装脚本审批策略，并对必须执行 install script 的包建立 allowlist。
