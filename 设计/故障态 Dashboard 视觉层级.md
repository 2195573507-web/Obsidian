# 故障态 Dashboard 视觉层级

> 上级入口：[[设计/设计 MOC|设计 MOC]]、[[产品/Monitor 首页信息架构|Monitor 首页信息架构]]。

## 目标

故障态 Dashboard 需要快速传递严重程度、影响范围和下一步，而不是用一堆同等权重的红色数字制造焦虑。

## 视觉层级

1. 全局状态：正常、降级、故障。
2. 影响范围：用户、任务、provider、服务。
3. 关键指标：最多 3-5 个。
4. 下一步操作：查看详情、暂停补跑、切 fallback。
5. 原始日志：放在二级页面。

## 设计原则

- 红色只用于需要立即处理的状态。
- 黄色用于观察或降级。
- 灰色用于未知或无数据。
- 卡片标题用人话描述，不只写指标名。
- 每张异常卡片给证据和入口。
