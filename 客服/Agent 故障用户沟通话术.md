# Agent 故障用户沟通话术

> 上级入口：[[客服/客服 MOC|客服 MOC]]、[[产品/Agent 产品失败兜底体验|Agent 产品失败兜底体验]]。

## 目标

Agent 故障沟通要清楚、短、可行动。避免把内部错误堆栈直接发给用户，也不要空泛承诺“稍后处理”。

## 模板：部分完成

“任务已完成一部分：{已完成项}。{未完成项} 因 {可理解原因} 暂停。我已经保留当前产物：{路径/链接}。建议下一步：{重试/等待/人工确认}。”

## 模板：上游失败

“这次失败更像模型/上游服务异常，不是你的输入问题。我建议先暂停批量重试，等轻量验证恢复后再低并发补跑，避免重复失败和额外成本。”

## 模板：需要授权

“这一步会修改 {影响范围}，需要你确认后再执行。我会先给出命令/变更摘要、风险和回滚方式，不会绕过审批。”

## 检查清单

- 是否说明当前状态。
- 是否说明影响范围。
- 是否给出下一步。
- 是否避免泄露敏感内部信息。
- 是否没有承诺无法保证的完成时间。
