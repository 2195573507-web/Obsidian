# 本地化流程

> 用于产品、文档和 UI 的多语言适配。

上级入口：[[写作/技术文档写作规范|技术文档写作规范]]。

## 核心框架

本地化不只是翻译，还包括日期、货币、单位、文化语境、法规、搜索词和客服支持。

## 实践清单

抽离文案；保留术语表；避免硬编码；让本地用户审校关键页面；记录不可翻译的产品名和 API key。

## 风险与边界

本页提供通用知识框架，不替代实时检查、专业法律/医疗/财务意见或项目现场判断。使用时应结合具体上下文、数据来源和最新状态。

## 应用方式

- 用作方案设计前的检查框架。
- 用作 Agent 执行任务时的上下文材料。
- 用作复盘后沉淀稳定经验的模板。
- 涉及实时状态、价格、政策、健康建议或法律意见时，必须补充时间戳和专业来源。
