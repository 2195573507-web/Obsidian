# AI Agent 误操作案例库

> 用于收集 Agent 自动化中的误操作与防线。

上级入口：[[AI/安全/Agent 安全与权限边界|Agent 安全与权限边界]]。

## 核心模型

常见误操作包括误删文件、误改配置、执行网页注入命令、把历史事实当当前状态、未验证即汇报成功。

## 执行步骤

记录触发 prompt、工具调用、影响范围、缺失防线、修复动作和新增规则。

## 边界与风险

使用时注意区分通用知识与当前事实；涉及法规、健康、财务、安全状态时必须补充最新来源和时间戳。

## 可复用输出

- 一页式摘要：背景、目标、约束、方案、风险、下一步。
- 执行清单：输入、步骤、验收、回滚、负责人。
- 复盘记录：事实、根因、改进、沉淀链接。
