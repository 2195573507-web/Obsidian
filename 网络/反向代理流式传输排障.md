# 反向代理流式传输排障

> 上级入口：[[网络/网络 MOC|网络 MOC]]、[[运维/Nginx 与反向代理排障手册|Nginx 与反向代理排障手册]]。

## 常见问题

流式接口在反向代理后可能出现首 token 慢、chunk 聚合后一次性返回、连接提前断开、客户端取消未传递到上游等问题。

## 检查项

- 是否启用代理 buffering。
- 是否设置合理 read timeout。
- 是否正确传递 `Connection`、`Upgrade`、`Cache-Control`。
- 是否有中间层压缩或缓存。
- 客户端取消后上游连接是否释放。

## 排查顺序

1. 直连上游测试 streaming。
2. 通过代理测试 first token 和 chunk gap。
3. 对比 Nginx/access/error 日志时间戳。
4. 检查代理 buffering 与 timeout。
5. 检查应用是否 flush 输出。
