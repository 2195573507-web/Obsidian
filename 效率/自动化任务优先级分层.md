# 自动化任务优先级分层

> 上级入口：[[效率/效率 MOC|效率 MOC]]、[[健康/自动化工作负载与注意力保护|自动化工作负载与注意力保护]]。

## 目标

当自动化任务很多时，必须分层处理。所有任务都“立刻补跑”会造成资源挤兑和注意力噪音。

## 分层模型

| 层级 | 类型 | 处理方式 |
|---|---|---|
| P0 | 安全/生产事故 | 立即提醒，人工确认 |
| P1 | 核心日报/关键巡检 | 低并发补跑 |
| P2 | 普通资讯/学习报告 | 可延后，合并汇报 |
| P3 | 高频心跳/进度汇报 | 失败静默或降频 |
| P4 | 实验性任务 | 只记录，不打扰 |

## 使用方法

1. 给每个 cron/report 任务标记优先级。
2. 补跑时从 P0/P1 开始。
3. P2 合并窗口补跑。
4. P3 连续失败后自动静默。
5. P4 只进入报告，不主动通知。
