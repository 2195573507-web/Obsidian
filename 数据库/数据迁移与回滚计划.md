# 数据迁移与回滚计划

> 用于安全修改 schema 和批量数据。

上级入口：[[软件工程/SQLite 到服务化数据库迁移指南|SQLite 到服务化数据库迁移指南]]。

## 核心框架

迁移分为 schema 迁移、数据回填、应用兼容和清理旧字段。风险在于长锁、不可逆变更和应用版本不兼容。

## 实践清单

先备份；小批量；可重复；记录进度；应用先兼容新旧字段；确认后再删除旧字段。
